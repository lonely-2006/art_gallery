# Art Gallery Project

## Purpose
The Art Gallery Project is designed to showcase a collection of artwork seamlessly and interactively. It allows users to explore various pieces of art, learn about the artists, and appreciate the artwork in a digital format. This project aims to promote artists and make art more accessible to everyone.

## Structure
The project is structured as follows:

```
/art_gallery
├── index.html       # Main page of the gallery
├── styles/          # Folder containing CSS files for styling
│   └── main.css     # Main stylesheet
├── scripts/         # Folder containing JavaScript files for functionality
│   ├── app.js       # Main application script
│   └── gallery.js    # Gallery specific scripts
├── images/          # Folder containing images of the artwork
└── README.md        # Documentation for the project
```

## Features
- **Interactive Gallery:** Users can view artwork in a grid layout with hover effects.
- **Responsive Design:** The layout adapts to various screen sizes, making it usable on mobile devices.
- **Artist Information:** Each artwork includes details about the artist, including a brief bio and other artwork.
- **Search Functionality:** Users can search for artworks by title, artist, or medium.

## How to Use
1. **Clone the repository:** 
   ```shell
   git clone https://github.com/lonely-2006/art_gallery.git
   ```
2. **Open index.html in your browser:** 
   Navigate to the project folder and open the `index.html` file to view the gallery.
3. **Explore Artworks:**  
   Browse through the artworks and click on each piece to learn more about it and the artist.
